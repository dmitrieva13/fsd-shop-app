# FSD-Shop-App
Этот проект представляет собой простое веб-приложение магазина, состоящее из страниц каталога товаров и корзины. При разработке использовалась методология **FSD (Feature-Sliced Design)** и библиотека **MobX**.

В приложении реализованы возможности добавления, удаления и изменения количества товаров в корзине, debounce-поиска по названию. Информация о состоянии корзины (количество товаров, сумма, кнопки в карточках товаров) обновляется мгновенно без необходимости перезагружать страницу.

**Стек технологий:** 
* TypeScript
* React
* CSS
* FSD
* MobX
* HTML


## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/dmitrieva13/fsd-shop-app.git
    cd fsd-shop-app
    ```
2. Установите Node.js с [официального сайта](https://nodejs.org/en/download)
3.  Установите необходимые библиотеки:
    ```bash
    npm install
    ```

## Запуск
1.  Запустите проект:
    ```bash
    npm start
    ```
2.  Проект запустится в браузере по ссылке `localhost:3000`

## Использование
- На странице каталога можно добавить интересующие товары в корзину; для товаров в корзине - уменьшить или увеличить их количество (пока есть доступный товар). Количество товаров в корзине отображается наверху страницы рядом с надписью "Корзина".
- На странице каталога доступен поиск по названию товара. Отфильтрованные товары появятся после окончания ввода текста. Чтобы вернуться ко всем товарам, сотрите введенный текст или нажмите крестик в поле ввода.
- На странице корзины отображается информация о каждом товаре, общая стоимость каждого товара и всей корзины. Прогресс бар показывает, сколько в корзине не хватает до суммы, после которой применится скидка.
- Количество товара в корзине можно изменить или полностю удалить товар из корзины. Удаление товара из корзины можно отменить в течение 3 секунд, нажав на кнопку отмены.

## Тестирование
1.  Запустите тесты:
    ```bash
    npm run test
    ```
2.  Информация о прохождении тестов и статусах появится в окне Терминала.

## Запуск Storybook
1.  Запустите Storybook проекта:
    ```bash
    npm run storybook
    ```
2.  Storybook запустится в браузере по ссылке `localhost:6006`

## Структура проекта
-   `src/shared` - переиспользуемый в приложении код без бизнес-логики
-   `src/entites` - сущности проекта (product, cart item, MobX-сторы)
-   `src/features` - функции, используемые в приложении (изменение коичества товара в корзине, поиск)
-   `src/widgets` - виджет-блоки, которые объединяют сущности и фичи (сетка продуктов, список товаров в корзине, хедер)
-   `src/pages` - страницы приложения
-   `src/app` - инициализация приложения, глобальные стили, роутинг
-   `tsconfig.json` - инструкция для TypeScript
-   `webpack.config.cjs` - инструкция для сборки приложения
-   `jest.config.js` - инструкция для корректной сборки тестов
-   `.storybook` - папка с инструкциями и настройкой Storybook
